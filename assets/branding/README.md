# Alan Studio and AlanBlox artwork

The inline briefing images served as visual direction. The developer authorized generated replacements when the original source files were unavailable. The four PNGs in this folder preserve the generated source images. The game uses the WebP studio logo, game logo, and splash backdrop in `runtime/`. Both logo layers preserve alpha. The background and game wordmark remain separate.

`icon-preview/` contains six proposed launcher files for review. The manifest, Apple touch icon, favicon, and service-worker install still use the original Phase 7 files in `icons/`. The preview icons have opaque edge-to-edge backgrounds. Their dedicated maskable versions use a padded center composition.
